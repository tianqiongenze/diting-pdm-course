# 课件说明

16 套课件位于 `pptx/`，命名规则：`第NN讲_主题.pptx`。

## 特点

- 16:9，1080p 投影适配
- 每页含**讲稿备注**（PowerPoint 放映时按"演讲者视图"可见）
- 统一视觉：深蓝工业底 + 橙色强调，无第三方模板依赖
- 内容与 `03_课程教学方案/`、`09_项目任务书/` 一一对应

## 重新生成

```bash
python tools/build_slides.py            # 全部
python tools/build_slides.py --only 7   # 只重建第 7 讲
```

内容源：`tools/src/content_m1.py` ~ `content_m4.py`（每个模块一个文件）。

> 不要直接改 pptx：下次重建会覆盖。要改内容请改 `content_m*.py`。

## 排版约束（改内容时遵守）

| 项 | 约束 |
|---|---|
| 每页要点 | ≤ 5 条 |
| 每条字数 | ≤ 28 字（超出会换行，影响版面） |
| 表格行数 | ≤ 7 行（含表头） |
| 代码行数 | ≤ 17 行 |
| 讲稿备注 | 每页必写，1–3 句，写"怎么讲"而不是"讲什么" |
